So installieren Sie die CoinPlay APK auf Android

Die Installation dauert etwa eine Minute. Die Bildschirme können je nach Handymarke leicht abweichen.

⬇ APK herunterladen

Schritt für Schritt

APK herunterladenVerwenden Sie die Download-Schaltfläche auf dieser Seite. Warten Sie, bis die Datei heruntergeladen ist.
Browser-Warnung schließenChrome weist möglicherweise darauf hin, dass diese Dateiart Ihrem Gerät schaden kann. Wählen Sie bei einer Datei aus der offiziellen Quelle „Trotzdem herunterladen“.
Datei öffnenTippen Sie auf die Benachrichtigung oder suchen Sie die Datei unter Dateien → Downloads.
Installation aus Ihrem Browser erlaubenAndroid zeigt die Meldung „Aus Sicherheitsgründen darf Ihr Smartphone keine unbekannten Apps aus dieser Quelle installieren“. Tippen Sie auf Einstellungen und aktivieren Sie „Aus dieser Quelle zulassen“.
Auf „Installieren“ tippenWenn Play Protect anbietet, die App zu scannen, können Sie den Scan oder „Trotzdem fortfahren“ wählen.
CoinPlay öffnenMelden Sie sich an oder registrieren Sie sich.

App aktualisieren

Laden Sie die neueste APK von dieser Seite herunter und installieren Sie sie über die vorhandene Version. Ihr Konto und Ihr Guthaben sind nicht betroffen.

Fehlerbehebung

  • „App nicht installiert“: Prüfen Sie den freien Speicher, entfernen Sie eine ältere, aus einer anderen Quelle installierte Version und versuchen Sie es erneut.
  • Die Datei lässt sich nicht öffnen: Stellen Sie sicher, dass der Download vollständig ist, und laden Sie die Datei in einem anderen Browser erneut herunter.
  • Einstellung nicht zu finden: Bei manchen Handys finden Sie sie unter Einstellungen → Apps → Spezieller App-Zugriff → Unbekannte Apps installieren.
