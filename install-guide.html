How to install the CoinPlay APK on Android

The installation takes about a minute. Screens vary slightly by phone brand.

⬇ Download APK

Step by step

Download the APKUse the download button on this site. Wait for the file to finish downloading.
Dismiss the browser warningChrome may say this type of file can harm your device. Choose “Download anyway” for a file from the official source.
Open the fileTap the notification, or find it in Files → Downloads.
Allow installs from your browserAndroid will show “For your security, your phone is not allowed to install unknown apps from this source”. Tap Settings and enable “Allow from this source”.
Tap InstallIf Play Protect asks to scan the app, you can choose to scan or continue.
Open CoinPlaySign in or register.

Updating the app

Download the latest APK from this site and install it over the existing version. Your account and balance are not affected.

Troubleshooting

  • “App not installed”: check free storage, remove an older copy from another source and try again.
  • File will not open: make sure the download finished; download again in another browser.
  • Setting not found: on some phones it is under Settings → Apps → Special access → Install unknown apps.
